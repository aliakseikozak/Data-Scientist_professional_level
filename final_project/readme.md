# TimeColor Telegram Bot @TimeColor_bot

Telegram-бот для стилизации и раскрашивания черно-белых фотографий с использованием нейросетевых моделей.

## 🚀 Возможности
- 9 стилей обработки фото: от реалистичного раскрашивания до винтажных эффектов
- Автоматическое определение ЧБ/цветных фото: интеллектуальная обработка
- Полная статистика: отслеживание активности пользователей и популярности стилей
- Админ-панель: управление ботом и просмотр аналитики
- Обратная связь: сбор отзывов от пользователей

## 🎨 Доступные стили
- Реалистично 🖼️ - естественное раскрашивание ЧБ фото
- Холодные тона ❄️ - холодная, синеватая цветовая гамма
- Ретро / Сепия 🎞️ - классический коричневый фильтр
- Советские 📻 - стиль старых советских фото
- Дореволюционные 🏰 - эффект старины с лёгким размытием
- 90-е 📼 - яркие, насыщенные цвета в стиле 90-х
- Современные 📷 - современное раскрашивание ЧБ фото
- Винтаж Европа/Америка 🇪🇺 - винтажный эффект
- Ретро (50-80) 🕰️ - стиль середины 20 века с виньетированием

## 📦 Установка и запуск
### 1. Клонирование репозитория
```bash
git clone https://github.com/aliakseikozak/Data-Scientist_professional_level/tree/main/final_project
cd final_project
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```
**requirements.txt:**
```
aiogram==2.25.1
torch==1.13.1
torchvision==0.14.1
numpy==1.24.3
Pillow==9.5.0
scikit-image==0.19.3
opencv-python==4.7.0.72
```

### 3. Настройка бота
- Создайте бота через @BotFather
- Получите API-токен
- В файле `bot.py` замените:
```python
API_TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"
ADMIN_ID = ВАШ_TELEGRAM_ID
```

### 4. Запуск бота
```bash
python bot.py
```

## ⚙️ Архитектура проекта
**bot.py** - Главный модуль
- Обработка команд и сообщений Telegram
- Управление состояниями пользователей
- Админ-панель со статистикой
- Логирование действий
- Система обратной связи

**utils/pipeline.py** - Пайплайн обработки
- Определение ЧБ/цветных фото
- Применение выбранного стиля
- Интеграция с моделями раскрашивания
- Постобработка изображений

**utils/models.py** - Интерфейсы к моделям
- realistic_color() - реалистичное раскрашивание (SIGGRAPH17)
- cartoon_color() - стилизация "мультяшный" (ECCV16)
- modern_color() - современное раскрашивание (ECCV16)

**colorizers/** - Нейросетевые модели
- base_color.py - базовый класс для работы с LAB-цветовым пространством
- eccv16.py - легкая модель для быстрой стилизации
- siggraph17.py - продвинутая модель для реалистичного раскрашивания

## 🛠️ Функционал бота
- Отправка фото и выбор стиля обработки
- Автоматическое логирование обработанных фото
- Сбор отзывов пользователей
- Админ-панель с:
  - Статистикой фото (по дням, неделям, месяцам, за все время)
  - Статистикой пользователей
  - Детальной статистикой активности
  - Просмотром всех отзывов

## 📊 Статистика
- Статистика фото и пользователей ведется автоматически в файлах `photo_stats.txt` и `bot.log`
- Отзывы пользователей в файле `feedback.txt`
- Администратор может просматривать краткую и детальную статистику через меню бота

## 🔧 Особенности обработки
**Для черно-белых фото:**
- Автоматическое раскрашивание перед применением стилей
- Все 9 стилей доступны
- Рекомендуемые стили: "Реалистично", "Современные"

**Для цветных фото:**
- Стили "Реалистично" и "Современные" не применяются
- Доступны остальные 7 стилей для стилизации

## 🚀 Команды бота
- /start - Главное меню
- /stop - Завершить сессию (сбросить все данные)
- /help - Справка по использованию
- /stats - Быстрая статистика (только для админа)

## 📈 Файлы данных
- bot.log - логи всех действий бота
- feedback.txt - отзывы пользователей (формат: timestamp||user_id||text)
- photo_stats.txt - статистика обработки (формат: timestamp|user_id|style)

## 🛠 Технические детали
**Используемые технологии:**
- Aiogram - асинхронный фреймворк для Telegram Bot API
- PyTorch - фреймворк для нейросетей
- OpenCV/PIL - обработка изображений
- scikit-image - работа с цветовыми пространствами

**Модели:**
- ECCV16 (Zhang et al., 2016) - быстрая модель для стилизации
- SIGGRAPH17 (Zhang et al., 2017) - продвинутая модель для реалистичного раскрашивания

## 🐛 Устранение проблем
**Если бот не запускается:**
- Проверьте установку всех зависимостей
- Убедитесь в правильности API-токена
- Проверьте доступ к интернету

**Если фото не обрабатываются:**
- Убедитесь, что отправляете фото, а не документ
- Проверьте размер фото (рекомендуется до 10MB)
- Попробуйте другой стиль
