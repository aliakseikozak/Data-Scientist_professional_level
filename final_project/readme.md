
# TimeColor Telegram Bot @TimeColor_bot

Telegram-бот для стилизации и раскрашивания черно-белых фотографий с использованием нейросетевых моделей.

## 🚀 Возможности
- 9 стилей обработки фото: от реалистичного раскрашивания до винтажных эффектов
- Автоматическое определение ЧБ/цветных фото: интеллектуальная обработка
- Полная статистика: активность пользователей и популярность стилей
- 👑 Админ-панель: аналитика, статистика, система уведомлений
- 📝 Интеллектуальная система обратной связи с анализом отзывов

## 🎨 Доступные стили
- Реалистично 🖼️ – естественное раскрашивание ЧБ фото  
- Холодные тона ❄️ – холодная цветовая гамма  
- Ретро / Сепия 🎞️ – классический эффект старых фото  
- Советские 📻 – стиль архивных советских снимков  
- Дореволюционные 🏰 – эффект старины с мягким размытием  
- 90-е 📼 – яркие и насыщенные цвета  
- Современные 📷 – современное нейтральное раскрашивание  
- Винтаж Европа/Америка 🇪🇺 – винтажный западный стиль  
- Ретро (50–80) 🕰️ – стиль середины XX века

## ⚙️ Архитектура проекта

### bot.py — Главный модуль
- Обработка команд и сообщений Telegram
- Управление состояниями пользователей
- Меню выбора стилей
- Логирование действий пользователей
- Админ-панель со статистикой и уведомлениями
- Система обратной связи

### utils/pipeline.py — Пайплайн обработки изображений
- Автоматическое определение ЧБ/цветных фото
- Разные пайплайны обработки в зависимости от типа изображения
- Интеграция со стилями и моделями раскрашивания
- Постобработка изображений
- Кеширование моделей для ускорения работы

### utils/models.py — Интерфейсы к моделям
- `realistic_color()` — реалистичное раскрашивание (SIGGRAPH17)
- `cartoon_color()` — стилизация ECCV16
- `modern_color()` — современное раскрашивание

### colorizers/
- `base_color.py` — работа с LAB-цветовым пространством
- `eccv16.py` — легкая модель для быстрой стилизации
- `siggraph17.py` — продвинутая модель для реалистичного раскрашивания

## 👑 Админ-панель

Доступна через меню для администратора (ID указан в `config.env`).

### 📊 Статистика
- Фото: сегодня / 7 дней / 30 дней / всё время
- Пользователи: активные и топ по активности
- Детальная аналитика: часы активности, популярные стили

### 📝 Анализ отзывов
- Классификация отзывов: баги, жалобы, похвалы, предложения, вопросы
- Анализ тональности
- Просмотр последних отзывов
- Формирование инсайтов

### 🔔 Система уведомлений
- Гибкая настройка категорий уведомлений
- Отправка уведомлений админу
- Отображение процента уверенности анализа
- Тестирование системы уведомлений

## ⚙️ Команды администратора
- `/stats` — краткая статистика
- `/feedback_stats` — статистика отзывов
- `/feedback_insights` — аналитические инсайты
- `/latest_feedback` — последние отзывы
- `/test_notify` — тест уведомлений
- `/notify_settings` — текущие настройки

## 🔧 Утилиты

### feedback_analyzer.py
**SimpleFeedbackAnalyzer**
- Анализ текста на основе ключевых слов
- Определение категории отзыва
- Расчет процента уверенности
- Сбор статистики и самообучение
- Интеграция с системой уведомлений

### pipeline.py
Интеллектуальный пайплайн обработки изображений:
- Автодетект ЧБ/цветных фото
- Оптимизированные пайплайны
- Кеширование моделей

## 🛠 Технические детали

### Используемые технологии
- Aiogram
- PyTorch
- OpenCV / PIL
- scikit-image

### Модели
- ECCV16 (Zhang et al., 2016) - лёгкая нейросетевая модель для автоматического раскрашивания ЧБ изображений, обеспечивает быструю работу и подходит для стилизации.
- SIGGRAPH17 (Zhang et al., 2017) - улучшенная модель раскрашивания с акцентом на реалистичную цветопередачу и сохранение деталей изображения.

### Система обратной связи
- SimpleFeedbackAnalyzer
- Система уведомлений
- Статистика и самообучение
